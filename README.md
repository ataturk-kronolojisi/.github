# Atatürk Kronolojisi'ne Hoş Geldiniz

Atatürk Kronolojisi, Mustafa Kemal Atatürk'ün yaşamını, mücadelesini ve Cumhuriyet'e uzanan tarihi süreci anlaşılır ve düzenli bir zaman akışı içinde sunmayı amaçlayan bir organizasyondur.

Web projemiz ise ziyaretçilere Atatürk'ün hayatındaki önemli olayları sade, erişilebilir ve tamamı Türkçe bir içerikle keşfetme imkânı sunar.
